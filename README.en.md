## 🚀 Projects

### 🦾 GDSense — Autonomous Warehouse Patrol Robot
*Apr 2026 — Present · [Gradisen](https://gradisen.com)*

An autonomous patrol robot for small-to-medium warehouses that detects packaging damage and verifies SKUs **without infrastructure modifications**. Built on an **NVIDIA Jetson** edge-AI pipeline with **ROS**, integrating a YOLO-based vision model, RGB-D camera, and 2D LiDAR to navigate fixed routes and identify structural anomalies with **over 80% accuracy**.

`ROS` `NVIDIA Jetson` `YOLO` `LiDAR` `RGB-D` `Sensor Fusion` `Autonomous Navigation`

### 📦 NovaSense — 3D Inventory Counting System
*Dec 2025 — Apr 2026*

An advanced Edge AI system for warehouse inventory counting and volumetric estimation. Evolved from a YOLO bounding-box model into a sophisticated **2D-3D spatial fusion pipeline** combining **Grounding DINO**, **SAM**, and **MASt3R**. Engineered a custom point-cloud denoising engine and elevation map voxelization to accurately measure irregular cargo shapes.

`3D Reconstruction` `Point Cloud Processing` `Computer Vision` `Edge AI` `Spatial Fusion`

### 🪑 Sitting Director — Smart Posture-Correcting Chair
*Sep 2022 — May 2023*

A smart chair system using an **ESP-32**, FSRs, and infrared sensors to detect and correct poor posture in real time. Implemented on-device pose estimation via **TensorFlow Lite** and **Google MoveNet**, syncing data to a custom **Android app** via **Firebase** and **BLE**. Designed 3D-printed mechanical components for physical posture adjustment.

`IoT (ESP-32)` `TensorFlow Lite` `Android (Java)` `Firebase` `BLE` `Hardware Integration`
